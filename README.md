## Лабораторная работа №1 — Мониторы

### Цель работы

Изучить механизм синхронизации потоков с помощью монитора и реализовать безопасное взаимодействие между потоком-поставщиком и потоком-потребителем.

### Задание

Разработать программу, содержащую два потока:

- **Поток-поставщик (Producer)** — создаёт события с интервалом в одну секунду и уведомляет потребителя.
- **Поток-потребитель (Consumer)** — ожидает появления события, получает его и выполняет обработку.

Программа должна обеспечивать правильную очерёдность сообщений, безопасный доступ к общим данным и минимальное использование процессорного времени во время ожидания.

### Реализация

Программа написана на языке C с использованием библиотеки POSIX Threads (`pthread`).

Для синхронизации используются:

- `pthread_mutex_t` — мьютекс для защиты разделяемых данных.
- `pthread_cond_t` — условная переменная для уведомления потоков.
- `pthread_cond_wait()` — ожидание события без активного использования процессора.
- `pthread_cond_signal()` — отправка уведомления другому потоку.
- `ready` — переменная, определяющая готовность события.
- `void* data` — указатель для передачи данных между потоками без сериализации.

Для хранения событий используется структура `Event`. Память выделяется динамически с помощью `malloc()` и освобождается функцией `free()` после обработки события.
